# 🌾 禾禾小冒险 - 多人联机网页游戏

一款多人联机文字冒险游戏，包含冒险、钓鱼、农场、锻造、技能、烹饪、同伴、世界BOSS等16个游戏子系统。

## 🚀 快速开始

```bash
cd hehe-web
npm install
npm start
```

浏览器打开 `http://localhost:3456` ，注册账号即可开始游玩。

## 🎮 游戏系统

| 系统 | 说明 |
|------|------|
| ⚔️ 冒险 | 外出冒险，随机遇到怪物/宝箱/商人/萝莉 |
| 🎣 钓鱼 | 装备鱼竿鱼饵，钓取30+种鱼类 |
| 🌾 农场 | 种植作物、养殖动物、培育果树、材料农场 |
| 🛒 商城 | 系统商城（每日刷新）+ 材料商店 + 玩家全球市场 |
| 🔨 锻造 | 消耗矿石材料锻造武器，附魔、镶嵌宝石 |
| 📚 技能 | 14个技能树，消耗技能点升级 |
| 🍳 烹饪 | 收集食材烹饪食物，食用获得战斗Buff |

## 🛠️ 技术栈

- **后端**: Node.js + Express + Socket.IO
- **前端**: Vanilla HTML/CSS/JavaScript（SPA）
- **数据**: JSON 文件存储
- **实时**: WebSocket（BOSS同步、市场广播）

## 📁 项目结构

```
hehe-web/
├── server/index.js        # 服务器入口（全部后端逻辑）
├── server/config/         # 游戏配置文件（36个JSON）
├── server/data/users/     # 用户数据存储
├── public/index.html      # 前端界面
└── package.json
```
